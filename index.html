Safety Management System (Preview)

โปรเจกต์นี้เป็นแอปแบบ SPA ที่พัฒนาด้วย Vite/React (TypeScript). เวอร์ชันที่เผยแพร่ต้องผ่านขั้นตอน build ก่อนจึงจะแสดงผลได้ถูกต้อง.

วิธีดูบน GitHub Pages

  1. ตั้งค่า GitHub Action ให้รัน npm run build แล้ว deploy ผลลัพธ์ไปยัง branch gh-pages หรือ commit ไฟล์ build ไปยัง main.
  2. หรือ ดาวน์โหลด repo แล้วรันบนเครื่อง: npm install → npm run build → serve ไฟล์ในโฟลเดอร์ dist.

ไปยัง repository บน GitHub

ถ้าต้องการ ผมช่วยตั้ง GitHub Action เพื่อ build & deploy ให้อัตโนมัติได้ — บอกได้เลยให้ทำต่อ.
